## 🚀 Projetos de Dados

### 💉 Saúde Vacinal Brasil — *destaque*
> **Python · MySQL · Power BI**

Análise da queda de cobertura vacinal no Brasil (2015–2023) usando dados públicos reais do governo. Pipeline com MySQL, tratamento em Python e dashboard com mapa geográfico no Power BI.

**Insight:** queda de 96% para 71,5% de cobertura, correlacionada ao surto de sarampo de 2019.

🔗 [Ver repositório](https://github.com/GabrielCruz079/saude-vacinal-brasil)
